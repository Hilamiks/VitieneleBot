VitieneleBot is a telegram bot that assists players in creating, managing, leveling up and sharing their characters in the game.

Contributing:
If you would like to add any features, feel free to submit a pull request for review :)

Steps to deploy:
1) Clone the repository
2) Create telegram bot using "BotFather" bot
3) Edit 'application.yml' to include the token and username of the created bot
4) Run maven package
5) Run the resuling .jar file
